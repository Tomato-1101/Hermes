# Hermes 操作ガイド
> 最終更新: 2026-05-31
> Hermes(Mode 1: 記録→編集→再生)を操作する人向けのガイドです。

---

## 1. Hermes とは

Hermes は、あなたがパソコン上で行った操作(ブラウザのクリックや入力、macOS アプリのクリックなど)を「記録」しておき、あとからボタン一つで「再生」して同じ操作を自動でなぞらせるツールです。毎日くりかえす定型作業を一度覚えさせれば、次からは Hermes がそのとおりに動いてくれます。記録した手順は一覧から並べ替えたり、待ち時間や条件を足したりと、あとから自由に編集できます。

---

## 2. 画面の構成

画面は左・中央・右の 3 つの領域(ペイン)に分かれています。

- **左:フロー一覧** — 作った手順(これを「フロー」と呼びます)の一覧です。ここで新規作成・選択・右クリックメニューからの操作を行います。
- **中央:エディタ** — 選んでいるフローの中身が並ぶ場所です。上部に操作用の「ツールバー」、その下に手順を縦に並べた「タイムライン」、いちばん下に動作の記録が流れる「ログ」があります。フロー名の右には、録画中は赤い「● 録画中」、再生中は「● 実行中」のしるしが出ます。
- **右:インスペクタ / アプリ設定 / シークレット** — 上から順に、選んだ手順の編集欄(「インスペクタ」)、ブラウザの起動方法や速度を決める「アプリ設定」、パスワードなどを安全に預ける「シークレット」、そしてアプリのバージョン等を表示する「環境」が縦に並びます。

---

## 3. フローを作る・開く・複製・名前変更・書き出し・削除

フローの管理はすべて左の「フロー」一覧で行います。

### 新しく作る
1. 左上の「新規」ボタンを押します。
2. 「新しいフローの名前は？」と聞かれるので、名前を入力して「OK」を押します。
   - 中央のエディタにフローがまだ開かれていないときは、中央の「+ 新規フロー」ボタンからでも同じことができます。

### 開く
- 一覧のフロー名をクリックすると、その中身が中央のエディタに開きます。選択中のフローは色が変わります。
- 各行には「○○ ステップ · 最終更新日時」が表示されます。

### 右クリックメニュー(複製・名前変更・書き出し・削除)
一覧のフローを右クリックすると、小さなメニューが出ます。

- **開く** — そのフローをエディタに開きます。
- **複製** — コピーを作ります。複製後の名前を聞かれます(初期値は「元の名前 (copy)」)。
- **名前を変更** — 新しい名前を入力します。
- **JSON をエクスポート** — フローの内容をファイル(`名前.flow.json`)として書き出します。バックアップや受け渡しに使えます。
- **削除** — そのフローを完全に削除します。確認画面が出て、「削除」を押すと手順・履歴・ブラウザの保存データごと消え、元には戻せません。

## 4. 操作を記録する

記録には「Web 録画(ブラウザの操作)」と「App 録画(macOS アプリの操作)」の 2 種類があります。録画ボタンは中央ツールバーの左側にあります。フローを開いていないと押せません。

### Web 録画(ブラウザ操作の記録)
1. ツールバーの「● Web 録画」を押します。
2. 「開始 URL(省略可、空白なら録画のみ開始)」と聞かれます。最初に開きたいページのアドレスを入れて「OK」を押します。空欄のまま「OK」でも始められます。
3. Hermes 用のブラウザが開きます。あとは普段どおりページ上でクリックや文字入力をしてください。操作した内容が中央のタイムラインにどんどん追加されていきます。
4. 終わったら、赤い「■ 録画停止」ボタンを押します。停止すると内容は自動で保存されます。

記録されるのは、クリック・文字入力・キー操作・ページ移動などです。パスワード欄に入力した値は、フローには直接残さず、安全な保管庫(シークレット)に自動で預けられます(第 8 章参照)。

### App 録画(macOS アプリ操作の記録)
1. ツールバーの「● App 録画」を押します。
2. ログに「Desktop 録画開始。クリック・修飾キーがグローバルに記録されます。停止するまで他のアプリで操作してください。」と出ます。
3. このモードは画面全体が対象です。Hermes の外に出て、記録したいアプリを普通に操作してください。クリック・キー操作・スクロール・ドラッグ・文字入力が記録されます。
4. 終わったら Hermes に戻り、「■ 録画停止」を押します。停止すると自動で保存されます。

※ App 録画は macOS でのみ使えます。

### 「録画待機」について
ツールバーの「録画待機」チェックを入れておくと、あなたが操作と操作の間で空けた「間(ま)」が、そのまま待ち時間として記録に取り込まれます。再生したときに、人が操作したのと近いリズムで動かしたいときに役立ちます。初期状態でオンです。

### 権限を求められたとき
App 録画や、再生でアプリ・画面を操作するとき、macOS から「Hermes に操作を許可しますか?」といった確認(アクセシビリティ、画面収録、入力監視など)が出ることがあります。表示されたら macOS の指示に従って「許可」してください。許可がないと録画が始まらない・再生が空振りする、といったことが起こります。許可がうまくいっていないときは、下のログに「permission not granted」「Screen Recording permission may be missing」などのメッセージが出ます。

## 5. ステップ(手順の 1 行)を編集する

タイムラインの各行が 1 つの「ステップ」です。行と行の間にカーソルを合わせると現れる丸い「＋」を押すと、その位置に新しいステップを差し込むメニューが開きます(いちばん下の「＋」は末尾への追加です)。ツールバーの「+ 待機」「+ 条件待機」「+ if」「+ loop」「+ try」ボタンからは、末尾にまとめて追加できます。

各行の右側のボタンで、↑↓ による並べ替え、× による削除ができます。

「＋」メニューは「待機・条件」と「構造」に分かれています。「待機・条件」には日常的な 3 つ(時間で待つ/ページのロード完了で次へ/要素の出現で次へ)が出ており、「高度な待機 ▸」を開くと残りの条件待機が現れます。各項目の意味は次のとおりです。

### 待機(時間で待つ)
決めた時間だけ、ただ何もせずに待ちます。
- いつ使うか:画面が切り替わるのに少しかかる、アニメーションが終わるのを待ちたい、といったとき。確実に「○秒待てば大丈夫」とわかっている場面に向きます。

### 条件待機(ある条件が満たされるまで待つ)
時間ではなく「状態」が整うまで待ちます。決めた状態にならないまま制限時間(タイムアウト)を過ぎると、その手順は失敗扱いになります。種別は次から選べます。
- **ページの読込完了** — 開いたページの読み込みが終わるまで待ちます(段階を「全リソースの読込まで/ページ構造の読込まで/通信が落ち着くまで」から選べます)。
- **要素の出現** — 指定した画面の部品が「表示された/ページに追加された/隠れた/消えた」状態になるまで待ちます。
- **URL の一致** — ブラウザの今のアドレスが、指定した文字列を含むようになるまで待ちます。
- **アプリ要素の出現** — macOS アプリの中の部品が現れるまで待ちます。
- **アプリが前面** — 指定したアプリが最前面(操作対象)になるまで待ちます。
- **ウィンドウのタイトル** — 最前面ウィンドウのタイトルが、指定したパターンに合うまで待ちます。
- **画面が落ち着いた** — 画面の見た目が一定時間変化しなくなる(安定する)まで待ちます。
- **条件式の成立** — 自分で書いた条件式が成り立つまで待ちます。
- いつ使うか:読み込みにかかる時間がそのときによってバラつく場合。「時間で待つ」だと短すぎて失敗・長すぎて遅い、を避けられます。たとえば「保存ボタンが表示されてから次に進む」など。

### if(条件分岐)
条件が成り立つかどうかで、進む道を変えます。条件が成り立てば「then(条件成立時)」の中の手順を、成り立たなければ「else(条件不成立時)」の中の手順を実行します。
- いつ使うか:「もしエラー表示が出ていたら閉じる、出ていなければそのまま進む」のように、状況によって動きを変えたいとき。

### loop(繰り返し)
中に入れた手順を、決めた回数だけくり返します(回数指定の「for」と、リストの各要素ごとにくり返す「forEach」が選べます)。
- いつ使うか:「同じ入力作業を 10 回くり返す」「リストにある名前を 1 件ずつ処理する」など、同じことを何度も行うとき。

### try(失敗してもとめないエラー処理)
「try 本体」を実行し、もし途中で失敗したら「catch」の中の手順を実行します。最後に「finally」の中の手順は成功・失敗にかかわらず必ず実行されます。
- いつ使うか:途中で失敗しても全体を止めたくないとき。「うまくいかなかったらスキップして後片付けだけはする」といった場面。

if・loop・try のような「入れ物」のステップには、中に子ステップを追加するための「+ ○○ ステップ」ボタンが、それぞれの枠の中に用意されています。

## 6. インスペクタでの調整

タイムラインで行をクリックすると、選択中になり、右の「インスペクタ」にその手順の編集欄が出ます(何も選んでいないときは「タイムラインからステップを選択するとここに表示されます。」と出ます)。

共通で出る項目:
- **タイプ** — その手順の種類(click、type など)。
- **ラベル** — 手順の表示名。自由に書き換えられます。空欄なら自動の説明文が表示されます。
- **有効** — チェックを外すと、その手順は再生時に飛ばされます。

種類ごとの項目:
- **待機** — 待つ時間を入力し、単位を「ms / 秒 / 分」から選べます。下の「条件型に変換」のボタンで、時間待ちを「ページの読込完了」など条件待機に切り替えられます。
- **条件待機** — 「条件種別」で待つ条件を選び、それに応じた入力欄(読込の段階、URL パターン、安定とみなす時間など)と「タイムアウト(ms)」が出ます。「時間待機に戻す」で時間待ちへ戻せます。
- **if** — 「条件」欄に分岐の条件式を書きます。
- **loop** — 「kind」で for(回数)か forEach(配列)を選び、回数や対象リストを入れます。

**対象(ターゲット)** — クリックや入力の手順には「対象」が表示されます。これは「どの部品を操作するか」を表し、「Web: ボタン〈ログイン〉」「アプリ: …」のように、どこの何を狙っているかが一行で要約されます。記録時に自動で付きます。

**詳細** — 各編集欄の下にある「詳細」を開くと、手順の ID や、ふだん触らない細かな設定(入力前のクリア、マウスボタン、文字認識の言語など)、操作対象の元データ(JSON)が見られます。通常は開く必要はありません。

**ヘルプの「?」** — 条件式の欄などにある丸い「?」マークにカーソルを合わせると、その項目で何が書けるか(使える変数や関数など)の説明が表示されます。

## 7. 再生する・止める

1. 中央ツールバーの「▶ 再生」を押すと、開いているフローが上から順に実行されます(手順が 0 個のとき、録画中のときは押せません)。未保存の変更があれば、再生の直前に自動で保存されてから始まります。
2. 実行中はフロー名の右に「● 実行中」が出ます。タイムラインでは、いま実行している行が強調表示され、どこを処理しているかがわかります。
3. いちばん下の「ログ」に進行状況が流れます。「Run ○○ started(開始)」、各手順の結果、最後に「Run ○○ success(成功)」または失敗が出ます。うまくいかなかった手順は警告として行番号付きで表示されます。ログは「クリア」で消せます。
4. 止めたいときは「■ 停止」ボタンを押します。**再生中はキーボードの ⌘(Command)+ ⇧(Shift)+ Esc を押すと、どのアプリにいても再生を中断できます。** 実行中はツールバーにもこのショートカットの案内が出ます。

## 8. シークレット(パスワード等)の保存

右ペインの「シークレット」欄では、パスワードや API キーなどの秘密の値を安全に預けられます。

- 「+ 追加」を押すと、シークレットの名前(例:password)を聞かれ、続けてその値を入力します。
- 一覧には名前だけが並びます。**値そのものは画面には決して表示されません。**
- 不要になったら名前の右の「×」を押し、確認で「DELETE」と入力すると削除できます。
- Web 録画でパスワード欄に入力すると、その値は自動でここに保存されます。

保存先は macOS の「キーチェーン」で、安全に管理されます。フロー側に残るのは値そのものではなく、`${secrets.名前}` という参照だけです。フローを書き出したり受け渡したりしても、秘密の値が一緒に出ていくことはありません。

---

## 9. 保存とやり直し

- **保存** — ツールバーの「保存」ボタン、またはキーボードの ⌘S で保存します。未保存の変更があるときは、ボタンが「保存*」のように「*」付きになります。録画を停止したときと、再生の直前には自動でも保存されます。
- **やり直し(Undo / Redo)** — 直前の編集を取り消すには ⌘Z、取り消したものをやり直すには ⌘⇧Z(または ⌘Y)を使います。ツールバーの ↶(取り消し)・↷(やり直し)ボタンからも同じことができます。

## 10. 困ったとき(かんたんトラブルシュート)

- **録画が始まらない / App 録画でクリックが記録されない** — macOS の操作許可(アクセシビリティ・入力監視など)が不足している可能性があります。許可を求める確認が出たら「許可」してください。ログに「permission not granted」などが出ていないか確認しましょう。
- **再生で部品をうまく見つけられない・空振りする** — 画面のレイアウトが録画時と変わっていたり、表示が間に合っていないことがあります。対象の手順の前に「条件待機(要素の出現/ページの読込完了)」を足して、表示を待ってから操作させると安定します。インスペクタの「ラベル」やラベル表示で、どの手順がどこを狙っているかを確認してください。
- **再生のたびに Chrome のログインが切れる / reCAPTCHA が頻発する** — 右ペインの「アプリ設定」で「ブラウザ起動」の方法を見直してください。「実 Chrome の Cookie/ログインを Hermes にコピー(推奨)」が標準です。それでも認証が頻発する場合のみ「実 Chrome プロファイルをそのまま使う」を試します(この方式は再生前に Chrome を ⌘Q で完全終了しておく必要があります)。
- **再生が始まらず「Chrome がまだ起動しています」と出る** — 「実 Chrome プロファイルをそのまま使う」方式のときは、再生前に Chrome を ⌘Q で完全に終了してください。
- **動きが速すぎる / 遅すぎる** — 「アプリ設定」の「マウス速度(px/秒)」「タイプ間隔(ms/文字)」で調整できます。推奨はマウス 800・タイプ 50 です。マウス速度 0 で瞬間移動、タイプ間隔 0 で一括入力になります。
- **再生がどうしても止まらない** — ⌘ + ⇧ + Esc で、どのアプリにいても中断できます。
